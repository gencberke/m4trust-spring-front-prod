# Architecture decisions

This directory contains the compact, topic-based architecture authority for
M4Trust.

Read [ADR-INDEX.md](ADR-INDEX.md) first. It defines the authority hierarchy and
links to the five active topic ADRs. Their current status is **Proposed — pending
independent acceptance**; accepted current capability remains in
[`docs/plan/CURRENT.md`](../docs/plan/CURRENT.md).

The numbered hackathon-era ADRs were intentionally removed rather than archived.
Their rationale remains recoverable through Git history and is not current
normative authority.
